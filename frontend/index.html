Connecting MetaMask to Local Hardhat Blockchain

1

Start Hardhat Local Network

Ensure your local blockchain node is running in the terminal:

cd blockchain
npx hardhat node
2

Add Custom RPC Network to MetaMask

In MetaMask, click network dropdown > Add a network > Add network manually:

  • Network Name: Hardhat Localhost
  • RPC URL: http://127.0.0.1:8545
  • Chain ID: 31337
  • Currency Symbol: ETH
